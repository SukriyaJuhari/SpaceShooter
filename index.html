About This Project

Space Shooter is a 2D arcade-style browser game built using the Phaser 3 framework. The player controls a spaceship and must survive waves of asteroids while firing projectiles and avoiding collisions.

Features

• Player spaceship with touch controls
• Dynamic asteroid spawning system
• Bullet firing system with visual effects
• Collision detection system
• Particle-style bullet impact effect
• Optimized for mobile browsers
• Built using Phaser 3 game framework

Tech Stack

JavaScript
Phaser 3
HTML5 Canvas
GitHub Pages Deployment
